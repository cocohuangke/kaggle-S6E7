## 1. 动机

当前 `pipeline/fe.py` (860行) 存在严重的项目耦合问题：

- **102处硬编码**，其中66处追溯到 `NUM_COLS`/`CAT_COLS` 两个全局常量 (fe.py:21-24)
- 每个FE函数都硬编码了列名 (如 `df['heart_rate']`, `df['bmi']`)
- 魔术数字散布各处 (`//5`, `*50`, `*10`, `-18.5`, `60`, `100`)
- 医学领域知识写死在代码中 (BMI阈值、心率阈值、睡眠阈值)
- 交互特征对硬编码 (`heart_rate×bmi`, `stress×pal`)
- GP发现的9个非线性公式不可迁移
- 3类分类假设硬编码在多处 (`np.zeros((N, 3))`)
- Tag系统13个单字母flag每个映射到项目特定特征
- `realmlp_fe()` 与 `fe.py` 大量重复代码 (~200行重复)

**目标**: 构建通用配置驱动的FE系统，换数据集只需改配置文件，不改代码。

## 3. 通用化可行性评估

### 3.1 容易通用化 (纯配置驱动)

| FE类型 | 通用化程度 | 原因 |
|--------|-----------|------|
| 缺失值填充 | 高 | median/zero/constant覆盖90%场景 |
| 编码方式 | 高 | label/onehot/ordinal/target/factorize，参数化 |
| 分箱策略 | 高 | equal_freq/equal_width/quantile + bins数 |
| 标准化 | 高 | standard/minmax/robust |
| 特征选择 | 高 | variance/correlation threshold |
| 基础数学变换 | 高 | log1p/sqrt/exp/sin/cos，单参数 |

### 3.2 部分通用化 (配置+模板)

| FE类型 | 通用化程度 | 配置模式 |
|--------|-----------|---------|
| num2cat变换 | 中 | `{col, op, by}` 三元组 |
| 交互特征 | 中 | `{type: cross/cross_bin, columns: [...]}` |
| Target Encoding | 中 | `{cv_folds, smoothing, min_samples}` |
| 阈值距离特征 | 中 | `{col, ref, op: subtract/rsubtract}` |
| 阈值分类 | 中 | `{col, bins: [...], labels: [...]}` |

### 3.3 必须留插件口

| FE类型 | 通用化程度 | 原因 |
|--------|-----------|------|
| GP非线性公式 | 低 | 数据集特定发现，需注册为自定义transform |
| 领域多列规则 | 低 | 如key_rule3，需自定义函数 |
| 复杂条件逻辑 | 低 | 如sleep_cat的条件分支，需表达式求值或自定义函数 |

## 4. 目标架构设计

### 4.1 核心原则

1. **数据契约与特征配置分离** — schema定义列名/类型/映射，features定义变换。换数据集只改schema。
2. **变换是声明式的** — 每个transform是 `{name, type, params}` 对象。type映射到注册函数，params提供参数。
3. **插件系统兜底** — 无法声明式表达的领域逻辑，注册为plugin。Plugin是Python函数，通过配置引用。
4. **format参数统一GBDT/NN** — 同一套FE配置，`format=gbdt`输出int+TE，`format=realmlp`输出category+无TE。
5. **维度自动计算** — 从resolved transforms列表动态计算，不hardcode。
6. **向后兼容** — 每阶段完成后，champion_v1.yaml必须产出相同OOF (0.95086)。

### 4.2 文件结构

```
pipeline/
```

### 4.4 schema.py 实现规范

```python
# pipeline/fe_v2/schema.py
import yaml
from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any

@dataclass
class ColumnDef:
    """单列定义。"""
    name: str
    dtype: str                          # 'numeric' | 'categorical'
    fill_value: Any = None              # 默认填充值
    ordinal: bool = False
    mapping: Optional[Dict[str, int]] = None

@dataclass
class TargetDef:
    """目标变量定义。"""
    column: str
    type: str                           # 'multiclass' | 'binary' | 'regression'
    classes: Optional[Dict[str, int]] = None
    n_classes: int = 0                  # 自动从classes计算

@dataclass
class ColumnSchema:
    """完整数据契约。"""
    version: str
    target: TargetDef
    id_column: str
    data_files: Dict[str, str]
    numeric_cols: List[ColumnDef]
    categorical_cols: List[ColumnDef]

    @property
    def all_columns(self) -> List[str]:
        return [c.name for c in self.numeric_cols + self.categorical_cols]

    @property
    def numeric_names(self) -> List[str]:
        return [c.name for c in self.numeric_cols]

    @property
    def categorical_names(self) -> List[str]:
        return [c.name for c in self.categorical_cols]

    def get_column(self, name: str) -> ColumnDef:
        """按名称查找列定义。"""
        for c in self.numeric_cols + self.categorical_cols:
            if c.name == name:
                return c
        raise ValueError(f"Column '{name}' not found in schema")

def load_schema(path: str) -> ColumnSchema:
    """从YAML文件加载schema。"""
    with open(path) as f:
        raw = yaml.safe_load(f)

    target = TargetDef(
        column=raw['target']['column'],
        type=raw['target']['type'],
        classes=raw['target'].get('classes'),
        n_classes=len(raw['target'].get('classes', {})),
    )

    numeric_cols = []
    for c in raw['columns'].get('numeric', []):
        numeric_cols.append(ColumnDef(
            name=c['name'], dtype='numeric',
            fill_value=c.get('fill_value'),
        ))

    categorical_cols = []
    for c in raw['columns'].get('categorical', []):
        categorical_cols.append(ColumnDef(
            name=c['name'], dtype='categorical',
            fill_value=c.get('fill_value', 'missing'),
            ordinal=c.get('ordinal', False),
            mapping=c.get('mapping'),
        ))

    return ColumnSchema(
        version=raw.get('version', '1.0'),
        target=target,
        id_column=raw.get('id_column', 'id'),
        data_files=raw.get('data_files', {}),
        numeric_cols=numeric_cols,
        categorical_cols=categorical_cols,
    )
```

### 4.5 Features配置 (特征工程)

Features配置定义变换序列。**换特征策略只改这个文件。**

```yaml
# features/gbdt_base.yaml
version: "1.0"
schema: s6e7                        # 引用schema文件名 (不含路径)

format: gbdt                        # gbdt | realmlp

imputation:
  numeric: median                   # median | zero | constant
  numeric_constant: 0               # 仅当numeric=constant时使用
  categorical: most_frequent        # most_frequent | constant
  categorical_constant: missing     # 仅当categorical=constant时使用

transforms:
  # --- num2cat系列 (在imputation之前执行，NaN→'missing') ---
  - name: calorie_cat_
    type: num2cat.floor_div
    column: calorie_expenditure
    by: 5
    before_fill: true               # 在imputation之前执行

  - name: water_cat2_
    type: num2cat.multiply_round
    column: water_intake
    by: 50
    before_fill: true

  - name: step_cat_
    type: num2cat.round
    column: step_count
    by: -1
    before_fill: true

  # --- 交叉特征 (在imputation之前执行) ---
  - name: stress_pal
    type: interaction.cross
    columns: [stress_level, physical_activity_level]
    separator: "_"
    fill_missing: MISSING           # NaN填充值
    before_fill: true

  # --- 阈值分类 (在imputation之前执行) ---
  - name: sleep_cat_
    type: binning.threshold_cat
    column: sleep_duration
    bins: [6, 7]                    # 分界点: <6, [6,7), >=7
    labels: [lt6, 6to7, ge7]
    nan_label: missing
    before_fill: true

  # --- 分箱 (在imputation之后执行) ---
  - name: sleep_70qbin_
    type: binning.kbin
    column: sleep_duration
    bins: 70
    strategy: quantile

  - name: water_10qbin_
    type: binning.kbin
    column: water_intake
    bins: 10
    strategy: quantile

  # --- 分箱交叉 (在imputation之后执行) ---
  - name: heart_bmi_
    type: interaction.cross_bin
    columns: [heart_rate, bmi]
    bins: 10
    strategy: quantile

  # --- 阈值距离特征 (在imputation之后执行) ---
  - name: bmi_dist_underweight
    type: distance.subtract
    column: bmi
    ref: 18.5
    output_type: int32: true

  - name: bmi_dist_overweight
    type: distance.rsubtract        # ref - col
    column: bmi
    ref: 24.9
    int32: true

  - name: hr_dist_low
    type: distance.subtract
    column: heart_rate
    ref: 60
    int32: true

  - name: hr_dist_high
    type: distance.rsubtract
    column: heart_rate
    ref: 100
    int32: true

  # --- GP非线性特征 (plugin) ---
  - name: gp_features
    type: plugin.gp_features
    module: pipeline.fe_v2.plugins.gp_features

  # --- 领域规则 (plugin) ---
  - name: key_rule3_
    type: plugin.health_rules.key_rule3
    module: pipeline.fe_v2.plugins.health_rules
    depends: [sleep_cat_]

encoding:
  # format=gbdt: LabelEncoder → int + 预计算TE
  # format=realmlp: factorize → category dtype + 无预计算TE
  target:
    enable: true
    columns: auto                   # auto = 所有cat列 (排除kbin列)
    exclude_pattern: "bin_"         # 排除列名包含此模式的列
    cv_folds: 5
    smoothing: auto
  numeric_target:
    enable: false                   # num TE需显式开启
    cv_folds: 5

selection:
  drop_features: []
  variance_threshold: null
  correlation_threshold: null
```

## 5. Transform注册表设计

### 5.1 Transform函数签名

每个transform函数遵循统一签名：

```python
# 签名约定
TransformFn = Callable[
    [pd.DataFrame, pd.DataFrame, dict, ColumnSchema],
    Tuple[List[str], dict]
]

# 参数:
#   train: pd.DataFrame   — 训练数据 (就地修改)
#   test: pd.DataFrame    — 测试数据 (就地修改)
#   params: dict          — 配置中的所有参数 (name, type, column, by, ...)
#                          — pipeline自动注入 '_format' (gbdt/realmlp)
#   schema: ColumnSchema  — 数据契约
#
# 返回:
#   new_cols: List[str]   — 新创建的列名列表
#   metadata: dict        — 列元数据
#     'type': 'categorical' | 'numeric'
#     'source': 源列名
#     'fitted': bool — 是否fit on train (如kbin, cross_bin)
#     'nan_handled': bool — 是否已处理NaN
```

### 5.2 registry.py 完整实现

```python
# pipeline/fe_v2/transforms/registry.py
from typing import Dict, Callable, List, Tuple, Any
import pandas as pd

TransformFn = Callable[
    [pd.DataFrame, pd.DataFrame, dict, Any],
    Tuple[List[str], dict]
]

class TransformRegistry:
    """通用变换注册表。

    每个transform type (如 'num2cat.floor_div') 映射到一个执行函数。
    函数签名统一: (train, test, params, schema) -> (new_cols, metadata)

    注册方式:
      1. 装饰器: @TransformRegistry.register("type.name")
      2. 直接: TransformRegistry._registry["type.name"] = fn

    type命名约定: {category}.{operation}
      - num2cat.floor_div, num2cat.multiply_round, num2cat.round, num2cat.multiply
      - binning.kbin, binning.threshold_cat
      - interaction.cross, interaction.cross_bin
      - distance.subtract, distance.rsubtract
      - math.log1p, math.sqrt, math.sin, math.cos, math.sigmoid, math.tanh
      - plugin.{module}.{func}
    """
    _registry: Dict[str, TransformFn] = {}

    @classmethod
    def register(cls, type_name: str):
        """装饰器: 注册transform type。"""
        def decorator(fn: TransformFn):
            if type_name in cls._registry:
                raise ValueError(f"Transform type '{type_name}' already registered")
            cls._registry[type_name] = fn
            return fn
        return decorator

    @classmethod
    def get(cls, type_name: str) -> TransformFn:
        if type_name not in cls._registry:
            raise ValueError(
                f"Unknown transform type '{type_name}'. "
                f"Available: {list(cls._registry.keys())}"
            )
        return cls._registry[type_name]

    @classmethod
    def list(cls) -> List[str]:
        return sorted(cls._registry.keys())

    @classmethod
    def has(cls, type_name: str) -> bool:
        return type_name in cls._registry
```

```python
      kb = KBinsDiscretizer(n_bins=n_bins, encode='ordinal', strategy='quantile')
      train[name] = kb.fit_transform(train[[col]]).ravel().astype('int32').astype(str)

        column: sleep_duration

    行为:
      - fit on train, transform on test
      - format=gbdt: 输出string列
      - format=realmlp: 输出category列 (factorize)
    """
    from sklearn.preprocessing import KBinsDiscretizer

    col = params['column']
    n_bins = params['bins']
    strategy = params.get('strategy', 'quantile')
    name = params['name']
    fmt = params.get('_format', 'gbdt')

    kb = KBinsDiscretizer(n_bins=n_bins, encode='ordinal', strategy=strategy, subsample=None)
    train_vals = kb.fit_transform(train[[col]]).ravel().astype('int32')
    test_vals = kb.transform(test[[col]]).ravel().astype('int32')

    if fmt == 'realmlp':
        codes, uniques = pd.Series(train_vals).factorize()
        train[name] = pd.Categorical.from_codes(codes, uniques)
        code_map = {cat: i for i, cat in enumerate(uniques)}
        tst_codes = pd.Series(test_vals).map(code_map).fillna(-1).astype('int32')
        test[name] = pd.Categorical.from_codes(tst_codes, uniques)
    else:
        train[name] = train_vals.astype(str)
        test[name] = test_vals.astype(str)

    return [name], {'type': 'categorical', 'source': col, 'fitted': True}
```

## 7. ConfigDrivenPipeline 设计

### 7.1 pipeline.py 核心类

```python
# pipeline/fe_v2/pipeline.py
import yaml
import hashlib
import os
import pickle
import numpy as np
import pandas as pd
from .schema import ColumnSchema, load_schema
from .transforms.registry import TransformRegistry

class ConfigDrivenPipeline:
    """配置驱动的特征工程Pipeline。

    使用方式:
      pipeline = ConfigDrivenPipeline.from_yaml('features/gbdt_base.yaml')
      X_train, X_test, cat_info = pipeline.fit_transform(train_df, test_df, y)

    核心流程:
      1. 加载schema + features配置
      2. 解析transforms列表，按before_fill分组
      3. 执行before_fill transforms
      4. 执行imputation
      5. 执行after_fill transforms
      6. 执行encoding (format-dependent)
      7. 执行selection
      8. 缓存结果 (key = hash(schema + features config))
    """

    def __init__(self, schema: ColumnSchema, config: dict):
        self.schema = schema
        self.config = config
        self.format = config.get('format', 'gbdt')
        self._fitted = False
        self._encoders = {}          # LabelEncoder等，fit on train
        self._te_encoders = {}       # TargetEncoder，fit on train
        self._metadata = {}          # 列元数据 {col_name: metadata_dict}

    @classmethod
    def from_yaml(cls, features_path: str, schema_dir: str = 'schema/') -> 'ConfigDrivenPipeline':
        """从YAML文件创建pipeline。"""
        with open(features_path) as f:
            config = yaml.safe_load(f)

        schema_name = config.get('schema', 's6e7')
        schema_path = os.path.join(schema_dir, f'{schema_name}.yaml')
        schema = load_schema(schema_path)

        return cls(schema, config)

    def fit_transform(self, train: pd.DataFrame, test: pd.DataFrame,
                      y: np.ndarray = None) -> tuple:
        """执行完整FE pipeline。

        Args:
            train: 训练集DataFrame
            test: 测试集DataFrame
            y: 训练集标签 (Target Encoding需要)

        Returns:
            (X_train, X_test, cat_info)
            - format=gbdt: X_train/X_test为numpy, cat_info为int列表 (cat列索引)
            - format=realmlp: X_train/X_test为DataFrame, cat_info为str列表 (cat列名)
        """
        # 检查缓存
        cache_key = self._cache_key()
        cached = self._load_cache(cache_key)
        if cached is not None:
            return cached

        # 深拷贝，不修改原始数据
        train = train.copy()
        test = test.copy()

        # 分组transforms
        before_fill, after_fill = self._split_transforms()

        # Step 1: before_fill transforms
        for t in before_fill:
            self._apply_transform(train, test, t)

        # Step 2: imputation
        self._apply_imputation(train, test)

        # Step 3: after_fill transforms
        for t in after_fill:
            self._apply_transform(train, test, t)

        # Step 4: encoding (format-dependent)
        cat_info = self._apply_encoding(train, test, y)

        # Step 5: selection
        self._apply_selection(train, test)

        # Step 6: format-specific output
        result = self._format_output(train, test, cat_info)

        # 缓存
        self._save_cache(cache_key, result)
        self._fitted = True

        return result

    def _split_transforms(self) -> tuple:
        """将transforms分为before_fill和after_fill两组。"""
        transforms = self.config.get('transforms', [])
        before = [t for t in transforms if t.get('before_fill', False)]
        after = [t for t in transforms if not t.get('before_fill', False)]
        return before, after

    def _apply_transform(self, train, test, t_config: dict):
        """执行单个transform。"""
        t_type = t_config['type']

        # plugin类型: 动态加载模块
        if t_type.startswith('plugin.'):
            self._apply_plugin(train, test, t_config)
            return

        # 注册表查找
        fn = TransformRegistry.get(t_type)
        params = {**t_config, '_format': self.format}
        new_cols, metadata = fn(train, test, params, self.schema)

        for col in new_cols:
            self._metadata[col] = metadata

    def _apply_plugin(self, train, test, t_config: dict):
        """执行plugin transform。"""
        module_path = t_config['module']
        t_type = t_config['type']

        # 动态import
        import importlib
        module = importlib.import_module(module_path)

        # plugin函数名 = type中plugin.之后的部分
        func_name = t_type.split('plugin.', 1)[1]
        # 支持点号: plugin.health_rules.key_rule3 → key_rule3
        if '.' in func_name:
            parts = func_name.split('.')
            obj = module
            for part in parts:
                obj = getattr(obj, part)
            fn = obj
        else:
            fn = getattr(module, func_name)

        params = {**t_config, '_format': self.format}
        new_cols, metadata = fn(train, test, params, self.schema)

        for col in new_cols:
            self._metadata[col] = metadata

    def _apply_imputation(self, train, test):
        """执行缺失值填充。"""
        imp = self.config.get('imputation', {})

        # numeric
        num_strategy = imp.get('numeric', 'median')
        for col_def in self.schema.numeric_cols:
            col = col_def.name
            if train[col].isna().any() or test[col].isna().any():
                if num_strategy == 'median':
                    fill_val = train[col].median()
                elif num_strategy == 'zero':
                    fill_val = 0.0
                elif num_strategy == 'constant':
                    fill_val = imp.get('numeric_constant', 0)
                else:
                    raise ValueError(f"Unknown numeric imputation: {num_strategy}")
                train[col] = train[col].fillna(fill_val)
                test[col] = test[col].fillna(fill_val)

        # categorical
        cat_strategy = imp.get('categorical', 'most_frequent')
        for col_def in self.schema.categorical_cols:
            col = col_def.name
            if train[col].isna().any() or test[col].isna().any():
                if cat_strategy == 'most_frequent':
                    fill_val = train[col].mode()[0]
                elif cat_strategy == 'constant':
                    fill_val = imp.get('categorical_constant', 'missing')
                else:
                    raise ValueError(f"Unknown cat imputation: {cat_strategy}")
                train[col] = train[col].fillna(fill_val)
                test[col] = test[col].fillna(fill_val)

    def _apply_encoding(self, train, test, y) -> list:
        """执行编码 (format-dependent)。

        Returns:
            cat_info: format=gbdt → int列表 (cat列索引)
                      format=realmlp → str列表 (cat列名)
        """
        enc_config = self.config.get('encoding', {})

        if self.format == 'realmlp':
            # factorize所有cat列 → category dtype
            cat_names = []
            for col in train.columns:
                if col in [c.name for c in self.schema.categorical_cols]:
                    cat_names.append(col)
                elif self._metadata.get(col, {}).get('type') == 'categorical':
                    cat_names.append(col)

            for col in cat_names:
                combined = pd.concat([train[col], test[col]], axis=0).astype(str)
                codes, uniques = pd.factorize(combined)
                n_train = len(train)
                train[col] = pd.Categorical.from_codes(codes[:n_train], uniques)
                test[col] = pd.Categorical.from_codes(codes[n_train:], uniques)

            return cat_names

        else:  # gbdt
            # LabelEncoder → int
            from sklearn.preprocessing import LabelEncoder
            cat_indices = []
            idx = 0
            for col in train.columns:
                if col in [c.name for c in self.schema.categorical_cols] or \
                   self._metadata.get(col, {}).get('type') == 'categorical':
                    le = LabelEncoder()
                    combined = pd.concat([train[col].astype(str), test[col].astype(str)])
                    le.fit(combined)
                    train[col] = le.transform(train[col].astype(str))
                    test[col] = le.transform(test[col].astype(str))
                    self._encoders[col] = le
                    cat_indices.append(idx)
                idx += 1

            # Target Encoding (如果启用)
            te_config = enc_config.get('target', {})
            if te_config.get('enable', False) and y is not None:
                self._apply_target_encoding(train, test, y, te_config)

            # Numeric Target Encoding
            nte_config = enc_config.get('numeric_target', {})
            if nte_config.get('enable', False) and y is not None:
                self._apply_numeric_target_encoding(train, test, y, nte_config)

            return cat_indices

    def _apply_target_encoding(self, train, test, y, te_config):
        """Cat列Target Encoding (GBDT专用)。"""
        # 实现同现有fe.py的target_encode()，但参数从配置读取
        cv_folds = te_config.get('cv_folds', 5)

    def _apply_numeric_target_encoding(self, train, test, y, nte_config):

    def _apply_selection(self, train, test):
        """执行特征选择。"""
        sel = self.config.get('selection', {})

        # drop_features

        # variance_threshold (TODO)

    def _format_output(self, train, test, cat_info) -> tuple:
        """格式化输出 (format-dependent)。"""
        if self.format == 'realmlp':
            # 返回DataFrame + cat列名列表
            return train, test, cat_info
        else:

    def _cache_key(self) -> str:

        config_str = yaml.dump(self.config, sort_keys=True)

            'numeric': self.schema.numeric_names,
            'categorical': self.schema.categorical_names,
        }, sort_keys=True)
        combined = config_str + schema_str
        return hashlib.md5(combined.encode()).hexdigest()[:12]

    def _load_cache(self, key: str):
        """从cache/fe_v2/加载缓存。"""
        cache_dir = 'cache/fe_v2'
        path = os.path.join(cache_dir, f'{key}.pkl')
        if os.path.exists(path):
            with open(path, 'rb') as f:
                return pickle.load(f)
        return None

    def _save_cache(self, key: str, result):
```

```python
# pipeline/fe_v2/plugins/gp_features.py
"""GP发现的非线性特征 (本项目特定)。

对应旧代码: fe.py:75-99 (add_gp_features)
  9个GP公式:
    1. sin(sleep_duration) * bmi
    2. sin(sleep_duration) * sigmoid(bmi)
    3. tanh(water_intake) * sin(sleep_duration) * sigmoid(calorie_expenditure)
    4. sin(sleep_duration) * log1p(step_count) - log1p(bmi)
    5. sin(sleep_duration) - tanh(calorie_expenditure)
    6. sin(sleep_duration) * log1p(step_count)
    7. sin(sleep_duration) * tanh(calorie_expenditure)
    8. sin(sleep_duration) * sqrt(abs(bmi))
    9. sin(sleep_duration) * log1p(abs(calorie_expenditure))
"""
import numpy as np
import pandas as pd

def _sigmoid(x, clip_min=-20, clip_max=20):
    return 1 / (1 + np.exp(-np.clip(x, clip_min, clip_max)))

def gp_features(train, test, params, schema):
    """GP非线性特征。"""
    fmt = params.get('_format', 'gbdt')
    prefix = '_gp_'

    for df in (train, test):
        sd = df['sleep_duration']
        bmi = df['bmi']
        wat = df['water_intake']
        cal = df['calorie_expenditure']
        step = df['step_count']

        df[f'{prefix}sin_sleep_x_bmi'] = np.sin(sd) * bmi
        df[f'{prefix}sin_sleep_x_sigmoid_bmi'] = np.sin(sd) * _sigmoid(bmi)
        df[f'{prefix}tanh_water_x_sin_sleep_x_sigmoid_cal'] = np.tanh(wat) * np.sin(sd) * _sigmoid(cal)
        df[f'{prefix}sin_sleep_x_log1p_step_minus_log1p_bmi'] = np.sin(sd) * np.log1p(step) - np.log1p(bmi)
        df[f'{prefix}sin_sleep_minus_tanh_cal'] = np.sin(sd) - np.tanh(cal)
        df[f'{prefix}sin_sleep_x_log1p_step'] = np.sin(sd) * np.log1p(step)
        df[f'{prefix}sin_sleep_x_tanh_cal'] = np.sin(sd) * np.tanh(cal)
        df[f'{prefix}sin_sleep_x_sqrt_abs_bmi'] = np.sin(sd) * np.sqrt(np.abs(bmi))
        df[f'{prefix}sin_sleep_x_log1p_abs_cal'] = np.sin(sd) * np.log1p(np.abs(cal))

    new_cols = [f'{prefix}sin_sleep_x_bmi',
                f'{prefix}sin_sleep_x_sigmoid_bmi',
                f'{prefix}tanh_water_x',
                f'{prefix}sin_sleep_x_log1p_step_minus_log1p_bmi',
                f'{prefix}sin_sleep_minus_tanh_cal',
                f'{prefix}sin_sleep_x_log1p_step',
                f'{prefix}sin_sleep_x_tanh_cal',
                f'{prefix}sin_sleep_x_sqrt_abs_bmi',
                f'{prefix}sin_sleep_x_log1p_abs_cal']

    return new_cols, {'type': 'numeric', 'source': 'gp_formulas'}
```

### 8.3 Health Rules Plugin

```python
# pipeline/fe_v2/plugins/health_rules.py
"""医学领域规则特征 (本项目特定)。

包含:
  - key_rule3: stress + pal + sleep_cat 三路交互
  - stress_bin: stress_level分箱
"""
import numpy as np
import pandas as pd

def key_rule3(train, test, params, schema):
    """三路交互: stress_level + physical_activity_level + sleep_cat_。

    对应旧代码: fe.py:186-199 (add_key_rule3)
      df['key_rule3_'] = (df['stress_level'].astype(str) + '_' +
                          df['physical_activity_level'].astype(str) + '_' +
                          df['sleep_cat_'].astype(str))

    配置:
      - name: key_rule3_
        type: plugin.health_rules.key_rule3
        module: pipeline.fe_v2.plugins.health_rules
        depends: [sleep_cat_]
    """
    name = params['name']
    fmt = params.get('_format', 'gbdt')

    for df in (train, test):
        result = (df['stress_level'].astype(str) + '_' +
                  df['physical_activity_level'].astype(str) + '_' +
                  df['sleep_cat_'].astype(str))
        if fmt == 'realmlp':
            codes, uniques = pd.Series(result).factorize()
            df[name] = pd.Categorical.from_codes(codes, uniques)
        else:
            df[name] = result

    return [name], {'type': 'categorical', 'source': 'stress+pal+sleep_cat'}

def stress_bin(train, test, params, schema):
    """stress_level分箱。

    对应旧代码: fe.py:179-181 (add_stress_bin)
      df['stress_bin_'] = df['stress_level'].map({'high': 2, 'medium': 1, 'low': 0})
    """
    name = params['name']
    mapping = params.get('mapping', {'high': 2, 'medium': 1, 'low': 0})

    for df in (train, test):
        df[name] = df['stress_level'].map(mapping).fillna(0).astype('int32')

    return [name], {'type': 'numeric', 'source': 'stress_level'}
```

## 10. 参考项目 (详细)

### 10.1 Feature Fabrica (cowana-ai)

- **GitHub**: https://github.com/cowana-ai/feature-fabrica
- **核心思想**: 每个特征是独立的YAML声明，通过Hydra `_target_` 实例化
- **关键模式**:
  ```yaml
  features:
    - name: calorie_cat
      _target_: feature_fabrica.transforms.FloorDiv
      column: calorie_expenditure
      by: 5
  ```
- **依赖解析**: 自动计算特征依赖DAG，按拓扑序执行
- **对我们的启发**: `_target_`模式让我们可以直接用`type`字段映射到注册函数，更简洁

### 10.2 feature-transform (kengz)

- **GitHub**: https://github.com/kengz/feature-transform
- **核心思想**: YAML → sklearn ColumnTransformer配置
- **关键模式**:
  ```yaml
  pipeline:
    - type: KBinsDiscretizer
      columns: [sleep_duration]
      params: {n_bins: 70, strategy: quantile}
  ```
- **Pydantic验证**: 配置文件加载后自动校验类型和参数
- **对我们的启发**: sklearn兼容的transformer可以复用，但我们的num2cat等不在sklearn中

### 10.3 mlproj (mjgmario)

- **GitHub**: https://github.com/mjgmario/mlproj
- **核心思想**: 完整的YAML驱动Kaggle框架
- **两层配置合并**:
  - `config/default.yaml` — 通用默认
  - `config/experiments/exp01.yaml` — 实验覆盖
- **inline表达式**: 支持 `{{ column * 50 }}` 语法
- **对我们的启发**: 两层合并模式适合我们: schema.yaml(数据集层) + features.yaml(实验层)

### 10.4 AlphaPy (ScottfreeLLC)

- **GitHub**: https://github.com/ScottfreeLLC/AlphaPy
- **核心思想**: 成熟的YAML ML框架
- **treatments插件系统**:
  ```yaml
  treatments:
    - name: gp_features
      module: pipeline.fe_v2.plugins.gp_features
  ```
- **`poly_degree` + `sampling_pct`**: 内置多项式特征和采样
- **对我们的启发**: treatments模式直接映射到我们的plugin系统

### 10.5 Featuretools (alteryx)

- **GitHub**: https://github.com/alteryx/featuretools
- **核心思想**: DFS (Deep Feature Synthesis) 自动特征合成
- **关键模式**: `agg_primitives × trans_primitives × max_depth` 自动组合
- **对我们的启发**: 过于重量级，不适合竞赛的精确控制需求。但primitive概念可参考

### 10.6 feature-engine (trainindata)

- **GitHub**: https://github.com/trainindata/feature-engine
- **核心思想**: 全面的sklearn兼容transformer库
- **覆盖**: 缺失值填充、编码、分箱、缩放、异常值、日期、文本、选择
- **对我们的启发**: 可选地集成feature-engine的transformer作为注册表后端

### 10.7 auto-bayesian (alvarofuentes)

- **GitHub**: https://github.com/alvarofuentes/auto-bayesian
- **核心思想**: TOML配置的关系型FE
- **关键模式**: `op/column/name` 三元组定义聚合
- **对我们的启发**: 关系型FE适合多表数据，本项目单表不需要

## 附录A: 设计决策记录

| 决策 | 选项 | 选择 | 原因 |
|------|------|------|------|
| 配置格式 | YAML vs TOML vs JSON | YAML | Kaggle社区惯例，支持注释 |
| Transform注册 | 装饰器 vs 配置文件 vs 自动发现 | 装饰器 | 编译时检查，IDE支持 |
| Plugin加载 | importlib vs entry_points vs Hydra | importlib | 无额外依赖，简单直接 |
| 缓存key | hash(config) vs 手动tag | hash(config) | 无需维护tag一致性 |
| 输出格式 | DataFrame vs numpy | format-dependent | GBDT用numpy快，RealMLP用DataFrame |
| Schema分离 | 合并在features中 vs 独立文件 | 独立文件 | 换数据集只改schema |
