# 04. LB预测公式

## 一句话总结

**v7线性公式（通用，MAE=0.00014）：`预测LB = blend_OOF + 0.00049 + 1.227 × health`，其中 health = max(单模型OOF) - blend_OOF。覆盖13d/14d/15d/triple/单模型/2模型/3模型所有路径。非balanced+CA路径仍可用v4（MAE=0.00007，更精确）。**

---

## ⚠️ 重要修正（v5）

### v4公式的失败案例

14d调参后（balanced XGB 3-model noCA）：
- OOF = 0.94947
- v4预测LB = 0.95037（+0.00033 vs 当前最优）
- **实际LB = 0.94978（-0.00026 vs 当前最优）**
- 误差 = -0.00059（v4声称MAE=0.00007的8倍）

### 失败根因

v4公式假设gap主要由模型数量决定（base_gap固定）。但balanced XGB noCA路径的数据显示：

| 配置 | OOF | LB | gap |
|------|-----|-----|-----|
| 14d eq noCA | 0.94797 | 0.95004 | +0.00207 |
| 14d BA2 noCA | 0.94811 | 0.95003 | +0.00192 |
| 14d tuned eq noCA | 0.94947 | 0.94978 | +0.00031 |

- LB几乎恒定在0.9498-0.9500
- gap从+0.00207缩到+0.00031（跨度0.00176）
- **OOF涨0.00150，LB反而降0.00026**

**结论**：balanced XGB noCA路径上，高OOF=过拟合，不是改进。

### v4公式的有效范围

v4公式在**非balanced XGB + CA路径**上仍然有效：

| 配置 | OOF | v4预测 | 实际LB | 误差 |
|------|-----|--------|--------|------|
| 13d BA2+CA | 0.94929 | 0.95003 | 0.94972 | +0.00031 |
| 14d BA2+CA | 0.94914 | 0.95008 | 0.95004 | +0.00004 |

但balanced XGB路径不能用v4。

### v5的验证与失败

提交3个tuned文件后，实测LB：

| 文件 | OOF | v5预测 | 实际LB | 误差 |
|------|-----|--------|--------|------|
| tuned eq noCA | 0.94947 | 0.94992 | 0.94978 | -0.00014 |
| tuned ba2 ca | 0.94948 | 0.94996 | 0.94978 | -0.00018 |
| tuned eq ca | 0.94947 | 0.94996 | 0.94978 | -0.00018 |

v5预测误差-0.00014~-0.00018，比v4的-0.00059好，但仍不准。

**v5失败的根因**：v5用旧配置数据（LB≈0.95003）预测新配置，无法检测配置健康度变化。

## 4.2 根本问题：为什么OOF ≠ LB？

### 现象

整个项目一直存在一个困扰：OOF高，LB反而低。

| 实验 | OOF BA | LB | gap (LB - OOF) |
|------|--------|-----|----------------|
| V3 (110d, 5模型) | 0.94986 | 0.94958 | -0.00028 |
| 13d baseline | 0.94929 | 0.94972 | **+0.00043** |
| 14d stress_pal | 0.94914 | 0.95004 | **+0.00090** |
| 15d sleep_stress | 0.94941 | 0.94966 | +0.00025 |
| 14d triple(64值) | 0.94930 | 0.94978 | +0.00048 |

gap从-0.00028到+0.00090，跨度0.00118。这个gap到底是什么？

### 三个根本原因

#### 原因1：数据量差异（最主要）

**OOF**：5折交叉验证，每折用80%训练数据训练，20%做验证。少数类样本数：

| 类别 | 训练集总量 | OOF每折训练量 | LB训练量 |
|------|-----------|---------------|----------|
| at-risk (85.8%) | 591,891 | 473,513 | 591,891 |
| unhealthy (8.4%) | 57,961 | 46,369 | 57,961 |
| fit (5.8%) | 40,022 | 32,018 | 40,022 |

**LB**：用100%训练数据训练，在test set预测。

少数类（unhealthy, fit）从80%→100%多了25%样本。对BA指标来说，少数类的recall权重与多数类相等，所以样本量增加25%能带来可观的BA提升。

**结论**：当模型健康（不过拟合、不偏倚）时，LB会系统性高于OOF。gap为正是常态。

#### 原因2：CA在OOF上的自我优化

CA（Coordinate Ascent）在50K OOF子样本上搜索最优的per-class乘子。这会让CA的scales"记住"OOF数据的噪声，导致：
- OOF被CA人为抬高
- gap = LB - OOF 被压缩（gap变小）

这是为什么"CA让OOF变高"但LB并不一定同步升高。

#### 原因3：5折CV方差

5折CV的方差大约 ±0.0002。小数据集上可能更大。

### 关键洞察：gap是诊断指标

- **gap为正且较大**（如+0.0009）：模型健康，数据量增益主导
- **gap接近0**：CA过度优化OOF，或模型开始过拟合
- **gap为负**（如V3的-0.00028）：模型严重过拟合，OOF虚高

整个项目从13d到14d到15d再到triple，gap的变化轨迹：

```
13d:    +0.00043 (健康)
14d:    +0.00090 (最健康)
15d:    +0.00025 (开始退化)
triple: +0.00048 (OOF虚高)
```

**14d是最健康的状态**，这也解释了为什么14d的LB=0.95004是最优。

## 4.3 公式推演过程

### v1：线性基础模型

**假设**：gap主要由数据量决定，不同模型数量有不同的增益。

```
预测LB = OOF + base_gap(model_count)
```

| 模型数 | base_gap |
|--------|----------|
| 5模型 | +0.00095 |
| 3模型 | +0.00090 |
| 2模型(CB+HGB) | +0.00025 |
| 1模型 | +0.00010 |

**结果**：MAE=0.00016，最大误差0.00056。

**问题**：无法解释为什么同样是3模型，有的gap=+0.0009，有的gap=+0.0003。CA的影响没考虑。

### v2：加入CA和交互特征惩罚

```
预测LB = OOF + base_gap + ca_eff + inter_eff + shallow_b + bagging_b
```

**ca_eff**：CA在OOF上的虚高程度
- 50K子样本CA：-0.00040
- 100K子样本CA：-0.00060
- 690K全量CA：-0.00085
- 无CA或balanced XGB（CA=[1,1,1]）：0

**inter_eff**：交互特征值数过多导致的过拟合
- 1-16值：0
- 32值：-0.00015
- 40值：-0.00030
- 64值：-0.00045
- 100+值（如V3的110d）：-0.00110

**shallow_b**：浅树+CA的组合增益
- depth≤5 + CA + 非balanced XGB：+0.00025

**bagging_b**：多seed集成
- 5 seed bagging：+0.00015

**结果**：MAE=0.00016（没改善），最大误差0.00054。

**问题**：ca_eff用固定值-0.00040，但实际发现不同配置下CA的虚高程度差异巨大。

### v3：细化inter_eff

发现triple的64值和40值的过拟合程度比v2估计的更严重。调整：

| 交互值数 | v2 | v3 |
|---------|-----|-----|
| 16值 | 0 | 0 |
| 32值 | -0.00015 | -0.00015 |
| 40值 | -0.00020 | -0.00030 |
| 64值 | -0.00030 | -0.00045 |

**结果**：MAE=0.00007，最大误差0.00040。大幅改善。

**遗留问题**：50K的ca_eff用固定-0.00040，但有些50K CA的配置gap压缩多，有些压缩少，无法解释。

### v4：CA虚高取决于scales偏离度（最终版）

**核心发现**：CA的虚高程度 = CA scales偏离[1,1,1]的程度。

定义scale偏离度：
```python
deviation = max(|scale_i - 1.0| for i in [at-risk, unhealthy, fit])
```

实测数据：

| 配置 | CA scales | deviation | 实际ca_eff |
|------|-----------|-----------|-----------|
| 14d BA2+CA | [0.7558, 1.0, 0.9889] | 0.244 | -0.00021 |
| 15d BA2+CA | [0.6246, 1.0, 0.7849] | 0.375 | -0.00032 |
| 13d BA2+CA | [0.5663, 1.4844, 0.9744] | 0.484 | -0.00041 |
| balanced XGB | [1, 1, 1] | 0 | 0 |

**新公式**：

```
ca_eff = -0.00085 × deviation  (当50K子样本CA时)
ca_eff = -0.00060 × (deviation / 0.5)  (当100K子样本CA时，简化)
ca_eff = -0.00085 × (deviation / 0.5)  (当690K全量CA时，简化)
ca_eff = 0  (当无CA或balanced XGB路径)
```

**物理含义**：CA对概率分布的修改幅度越大，OOF被虚高的程度越大，gap被压缩得越多。

**结果**：MAE=0.00007，最大误差0.00022，80%误差≤0.00014。

## 4.4 最终公式 v4

### 完整公式

```
预测LB = OOF + base_gap + ca_eff + inter_eff + shallow_b + bagging_b
```

### 参数表

| 参数 | 条件 | 取值 |
|------|------|------|
| **base_gap** | 5模型blend | +0.00095 |
| | 3模型blend (XGB+CB+HGB) | +0.00090 |
| | 2模型blend (CB+HGB) | +0.00025 |
| | 单模型 | +0.00010 |
| **ca_eff** | 无CA 或 balanced XGB路径(CA=[1,1,1]) | 0 |
| | 50K子样本CA | -0.00085 × deviation |
| | 100K子样本CA | -0.00060 × (deviation/0.5) |
| | 690K全量CA | -0.00085 × (deviation/0.5) |
| **inter_eff** | 1-16个唯一值 | 0 |
| | 17-32值 | -0.00015 |
| | 33-48值 | -0.00030 |
| | 49-80值 | -0.00045 |
| | 80+值 (如V3 110d) | -0.00110 |
| **shallow_b** | depth≤5 + CA + 非balanced XGB | +0.00025 |
| | 其他 | 0 |
| **bagging_b** | 5 seed bagging | +0.00015 |
| | 单seed | 0 |

### deviation的计算

```python
def calc_deviation(scales):
    """scales = [scale_at_risk, scale_unhealthy, scale_fit]"""
    return max(abs(s - 1.0) for s in scales)
```

例：
- scales=[0.7558, 1.0, 0.9889] -> deviation = max(0.2442, 0, 0.0111) = 0.2442
- scales=[1, 1, 1] -> deviation = 0
- scales=[0.5663, 1.4844, 0.9744] -> deviation = max(0.4337, 0.4844, 0.0256) = 0.4844

### 异常情况（公式不适用）

#### M-A（删除缺失行）单模型

| 实验 | OOF | LB | gap |
|------|-----|-----|-----|
| M-A CatBoost noCA | 0.96744 | 0.81431 | -0.153 |
| M-A CatBoost Balanced | 0.97023 | 0.844 | -0.126 |

**原因**：训练集删除了49%缺失行，但test set有44%行带缺失。训练分布与测试分布严重不匹配。模型在完整行上训练，但对带缺失的test行给出了错误预测。

**结论**：M-A策略的OOF完全不可信，公式不适用。这也是为什么我们最终放弃了M-A策略。

#### balanced XGB路径

当XGB使用balanced权重后，CA会返回[1,1,1]（无需校准）。但base_gap对"3模型blend with balanced XGB"的估计(+0.00090)偏低，实际gap可达+0.00207（14d xgbal eq noCA: OOF=0.94797, LB=0.95004）。

**推测原因**：balanced XGB本身就在做CA的工作（让3类概率平衡），所以blend后不需要CA。但balanced XGB的概率分布更"健康"，在test set上泛化更好，实际增益比公式估计的更大。

**修正**：对balanced XGB + noCA的3模型blend，base_gap可上调到+0.00207（但样本太少，暂不正式修改公式）。

## 4.6 使用方法

### 提交决策流程

```
1. 实验完成，得到OOF BA
2. 计算各参数：
   - base_gap: 数模型数量
   - ca_eff: 0 (如果noCA或balanced XGB) 或 -0.00085 × deviation (如果50K CA)
   - inter_eff: 看交互特征值数
   - shallow_b: 0.00025 (如果满足条件) 或 0
   - bagging_b: 0.00015 (如果5seed) 或 0
3. 预测LB = OOF + 上述5项之和
4. 决策：
   - 预测LB > 当前最优 + 0.00014 -> 提交
   - 预测LB ≤ 当前最优 -> 跳过，省配额
   - 预测LB > 当前最优 + 0.00030 -> 高优先级提交
```

### Python实现

```python
def predict_lb(oof, n_models, ca_scales=None, ca_subset_size=0,
               interaction_values=16, depth=7, xgb_balanced=False,
               n_seeds=1):
    """
    预测LB分数。

    参数:
        oof: float, OOF BA分数
        n_models: int, blend模型数 (1, 2, 3, 5)
        ca_scales: list or None, CA乘子 [at_risk, unhealthy, fit]
                   None表示无CA或balanced XGB路径
        ca_subset_size: int, CA搜索用的子样本量 (0, 50000, 100000, 690000)
        interaction_values: int, 最复杂交互特征的唯一值数
        depth: int, CatBoost/HistGB的最大树深
        xgb_balanced: bool, XGB是否使用balanced权重
        n_seeds: int, seed集成数量

    返回:
        predicted_lb: float
    """
    # base_gap
    base_gap_map = {1: 0.00010, 2: 0.00025, 3: 0.00090, 5: 0.00095}
    base_gap = base_gap_map.get(n_models, 0.00025)

    # ca_eff
    if ca_scales is None or xgb_balanced:
        ca_eff = 0
    else:
        deviation = max(abs(s - 1.0) for s in ca_scales)
        if ca_subset_size >= 690000:
            ca_eff = -0.00085 * (deviation / 0.5)
        elif ca_subset_size >= 100000:
            ca_eff = -0.00060 * (deviation / 0.5)
        else:  # 50K default
            ca_eff = -0.00085 * deviation

    # inter_eff
    if interaction_values <= 16:
        inter_eff = 0
    elif interaction_values <= 32:
        inter_eff = -0.00015
    elif interaction_values <= 48:
        inter_eff = -0.00030
    elif interaction_values <= 80:
        inter_eff = -0.00045
    else:
        inter_eff = -0.00110

    # shallow_b
    shallow_b = 0.00025 if (depth <= 5 and ca_scales is not None
                            and not xgb_balanced) else 0

    # bagging_b
    bagging_b = 0.00015 if n_seeds >= 5 else 0

    predicted_lb = oof + base_gap + ca_eff + inter_eff + shallow_b + bagging_b
    return predicted_lb


# 使用示例
# 14d stress_pal, 3模型, 50K CA, scales=[0.7558,1.0,0.9889], 16值交互, depth=5, 无balanced
lb = predict_lb(
    oof=0.94914,
    n_models=3,
    ca_scales=[0.7558, 1.0, 0.9889],
    ca_subset_size=50000,
    interaction_values=16,
    depth=5,
    xgb_balanced=False,
    n_seeds=1
)
# 预测LB = 0.94914 + 0.00090 + (-0.00021) + 0 + 0.00025 + 0 = 0.95008
# 实际LB = 0.95004, 误差 = +0.00004
```

## 4.7 公式的局限性

### 1. base_gap依赖经验值

base_gap的4个取值（0.00010/0.00025/0.00090/0.00095）是从历史数据拟合的。如果模型配置变化大（如换成LightGBM+RealMLP），这些值可能不准确。

### 2. inter_eff的分档较粗

交互特征值数与过拟合的关系是连续的，公式用分档近似（16/32/48/80/100+）。在档位边界附近（如17值或33值）可能误差较大。

### 3. balanced XGB路径估计偏低

balanced XGB + noCA路径的实际gap比公式预测的大。可能因为balanced权重让模型概率分布更健康，在test set上泛化更好。但样本数太少，暂不调整。

### 4. 不适用于分布不匹配的场景

M-A（删除缺失行）策略OOF虚高0.15+，公式完全失效。公式的前提是训练分布≈测试分布。

### 5. CA scales的deviation范围

公式假设50K CA的deviation在0-0.6之间。如果deviation>0.6（极端CA），公式可能不准。实际项目中没遇到过这种情况。

## 4.8 下一步优化方向

### 公式本身的优化

1. **收集更多数据点**：特别是balanced XGB路径，目前只有3-4个点，难以准确估计base_gap。
2. **细化inter_eff**：用连续函数代替分档（如 inter_eff = -0.00001 × values_count，当values_count > 16时）。
3. **加入seed方差**：多seed的方差本身能反映模型稳定性，可能有助于预测。

### 配合公式使用的实验策略

1. **一次一个变量**：每次实验只改一个参数（特征/模型/超参），方便公式预测。
2. **记录所有参数**：每次实验都记录OOF、CA scales、交互值数、depth、seed数等，方便事后修正公式。
3. **只在预测LB > 当前最优 + 0.00014时提交**：这是公式最大的价值--省配额。

## 4.9 总结

### 核心收获

这个公式解决了整个项目最大的痛点：**OOF高不代表LB高**。

以前看到OOF涨了就激动，结果LB退步。现在知道了：
- OOF涨可能只是CA虚高（ca_eff）
- OOF涨可能只是交互特征过拟合（inter_eff）
- 真正的LB增益 = OOF变化 + gap变化

### gap的诊断价值

| gap (LB - OOF) | 诊断 | 行动 |
|----------------|------|------|
| > +0.0007 | 模型非常健康 | 继续当前方向 |
| +0.0003 ~ +0.0007 | 健康 | 正常推进 |
| +0.0001 ~ +0.0003 | 边界 | 观察是否退化 |
| -0.0002 ~ +0.0001 | 可能过拟合 | 停止加特征 |
| < -0.0002 | 严重过拟合 | 回退到上一版本 |

### 当前最优配置的gap

## 4.10 v5修正：balanced XGB路径的特殊性

### 问题回顾

14d调参实验（balanced XGB 3-model noCA）：
- OOF: 0.94797 → 0.94947（+0.00150）
- v4预测LB: 0.95037
- 实际LB: 0.94978（**比预测低0.00059，比调参前退步0.00026**）

### 根本原因：LB是路径依赖的常数

balanced XGB noCA路径的所有数据点：

| 配置 | OOF | LB | gap |
|------|-----|-----|-----|
| 14d eq noCA | 0.94797 | 0.95004 | +0.00207 |
| 14d BA2 noCA | 0.94811 | 0.95003 | +0.00192 |
| 14d BA2 CA=[1,1,1] | 0.94914 | 0.95003 | +0.00089 |
| 14d CB+HGB noCA (2模型) | 0.94933 | 0.94955 | +0.00022 |
| 14d tuned eq noCA | 0.94947 | 0.94978 | +0.00031 |

**关键观察**：
1. LB范围 0.94955-0.95004，跨度仅0.00049
2. OOF范围 0.94797-0.94947，跨度0.00150
3. **LB几乎恒定，OOF大幅变化但LB不动**

### 线性拟合（3-model noCA balanced XGB）

对3个3-model noCA点拟合：

```
LB = 1.1184 - 0.1776 × OOF
```

slope = -0.1776（负斜率！）

**物理含义**：OOF每涨0.001，LB降0.00018。高OOF=过拟合。

### 两条路径的根本差异

| 路径 | 数据特征 | gap行为 | LB与OOF关系 |
|------|----------|---------|-------------|
| **非balanced XGB + CA** | CA修正XGB偏差 | gap相对稳定(+0.0004~+0.0009) | LB随OOF涨而涨 |
| **balanced XGB noCA** | 3模型自然平衡 | gap从+0.002缩到+0.0003 | LB恒定，OOF涨=过拟合 |

### 为什么两条路径行为不同？

#### 非balanced XGB + CA路径
- XGB有at-risk偏差（R0=0.991）
- CA修正这个偏差（scales=[0.71,1.0,0.99]）
- OOF提升 = 真实模型改进 + CA修正空间
- LB跟着OOF涨

#### balanced XGB noCA路径
- XGB已balanced，无偏差
- 3模型自然平衡，CA=[1,1,1]无修正空间
- OOF提升只能来自模型本身
- 但模型已接近上限，OOF提升=过拟合训练集噪声
- LB不涨甚至降

### v5修正公式

**判断路径**：
```python

    use_v5_formula()
else:  # 非balanced或CA非[1,1,1]
    use_v4_formula()  # 原公式仍有效
```

**v5公式（balanced XGB 3-model noCA）**：
```

```

或简化：
```

```

### v5公式的指导意义

1. **balanced XGB noCA路径已到顶**：LB≈0.9500是天花板
2. **不要在这条路径上调参**：OOF涨是过拟合，LB不会涨

## 4.12 v6发现：LB由配置健康度决定，不由OOF决定

### 3个tuned文件实测结果

| 文件 | OOF | v5预测 | 实际LB | v5误差 |
|------|-----|--------|--------|--------|
| tuned eq noCA | 0.94947 | 0.94992 | 0.94978 | -0.00014 |
| tuned ba2 ca | 0.94948 | 0.94996 | 0.94978 | -0.00018 |
| tuned eq ca | 0.94947 | 0.94996 | 0.94978 | -0.00018 |

### 核心发现：同一配置的3个文件LB完全相同

| 配置 | 文件数 | LB值 | LB标准差 |
|------|--------|------|----------|
| 旧配置 (HGB d8 l2=1, CB d5 l2=1) | 3个 | 0.95003-0.95004 | 0.00001 |
| **调参后** (HGB d5 l2=0, CB d5 l2=3) | 3个 | **0.94978** | **0.00000** |
| 旧配置 2-model (CB+HGB) | 1个 | 0.94955 | - |

**关键观察**：
1. 同一配置内，blend方式（Equal/BA2）和CA（有/无）对LB几乎无影响
2. **LB由配置本身决定，不由blend/CA/OOF决定**
3. 配置改变（HGB d8->d5, CB l2 1->3）导致LB均匀下降0.00026

### 配置健康度判据

| 指标 | 旧配置（健康） | 调参后（过拟合） |
|------|---------------|-----------------|
| XGB OOF | 0.94809 | 0.94809 |
| CatBoost OOF | 0.94909 | 0.94921 |
| HistGB OOF | 0.94927 | 0.94919 |
| **blend OOF** | **0.94797** | **0.94947** |
| blend vs max单模型 | 0.948 **<** 0.949 | 0.949 **≈** 0.949 |
| gap | +0.00207 | +0.00031 |
| **实际LB** | **0.95003** | **0.94978** |

### 健康度判据：blend_OOF vs max(单模型OOF)

**健康**：`blend_OOF < max(单模型OOF)`（blend比最强单模型低）
- 旧配置：blend=0.948 < HGB=0.949，差0.001
- 模型预测不同，blend有效，LB > OOF

**过拟合**：`blend_OOF ≈ max(单模型OOF)`（blend≈最强单模型）
- 调参后：blend=0.94947 ≈ HGB=0.94919，差仅0.0003
- 模型预测趋同，blend无增益，LB ≈ OOF

### v6公式方向

```
预测LB = OOF + gap
gap = f(配置健康度)

配置健康度 = max(单模型OOF) - blend_OOF

如果 健康度 > 0.001：gap ≈ +0.002（健康）
如果 健康度 < 0.0005：gap ≈ +0.0003（过拟合）
```

### 为什么blend_OOF是健康度指标？

**blend的本质**：多个模型预测平均，如果模型预测不同，平均后更稳健（OOF低但泛化好）；如果模型预测趋同，平均≈单模型（OOF高但无新信息）。

- **旧配置**：HGB d8（深树）和CB d5（浅树）深度不同，预测模式不同，blend有效
- **调参后**：HGB d5和CB d5都是浅树，预测趋同，blend=单模型，无增益

### 实用判据（无需公式）

提交前检查：
```
health = max(XGB_OOF, CB_OOF, HGB_OOF) - blend_OOF
```

| health值 | 诊断 | 预期gap | 行动 |
|----------|------|---------|------|
| > 0.0015 | 非常健康 | +0.002 | 模型有效，提交 |
| 0.0008-0.0015 | 健康 | +0.001 | 正常 |
| 0.0003-0.0008 | 边界 | +0.0005 | 可能过拟合 |
| < 0.0003 | 过拟合 | +0.0003 | **不要提交** |

### v6验证

| 配置 | health = max-blend | 实际gap | 诊断 |
|------|-------------------|---------|------|
| 旧 eq noCA | 0.94927-0.94797=0.00130 | +0.00207 | 健康 ✅ |
| 旧 BA2 noCA | 0.94927-0.94811=0.00116 | +0.00192 | 健康 ✅ |
| 旧 BA2 CA | 0.94927-0.94914=0.00013 | +0.00089 | 过拟合 ⚠️ |
| **调参后** | 0.94921-0.94947=**-0.00026** | +0.00031 | **严重过拟合** ✅ |
| 旧 CB+HGB | 0.94927-0.94933=-0.00006 | +0.00022 | 过拟合 |

**关键**：调参后health为负值（blend_OOF > max单模型OOF），这是过拟合的强信号！

### v6 vs v4/v5对比

| 版本 | 预测依据 | 误差 |
|------|----------|------|
| v4 | OOF + 固定参数 | -0.00059（balanced路径失效） |
| v5 | OOF线性拟合（同路径） | -0.00014~-0.00018 |
| **v6** | **配置健康度（health值）** | **待更多数据验证** |

v6的核心改进：不只看OOF绝对值，看blend与单模型的关系。

### v6的指导意义

1. **调参后health为负 = 过拟合**：blend比单模型还高，说明模型趋同，没有多样性
2. **不要提交health<0.0003的配置**：gap不会扩大，LB≈OOF
3. **调参目标不是提OOF，而是提health**：保持模型多样性

### 14d调参的教训

调参后单模型OOF：
- CB: 0.94909 -> 0.94921（+0.00012）
- HGB: 0.94927 -> 0.94919（-0.00008）
- blend: 0.94797 -> 0.94947（+0.00150）

blend涨了0.00150，远超单模型变化。这说明调参让3个模型的预测趋同了（都变成相似的浅树），blend失去多样性收益。

**正确做法**：调参时应监控health值，如果health下降，即使OOF涨也要停止。

- CB的LB提升(+0.00074)甚至超过OOF提升(+0.00069)
- HGB的LB提升(+0.00019)远小于OOF提升(+0.00067)
- **XGB绝对不能使用TE特征**

## OOF-LB Gap 分析

### Gap排序与特征对称性

| 模型/Blend | OOF-LB Gap | 特征对称性 | 可信度 |
|------------|-----------|-----------|--------|
| RealMLP | **-0.00003** | ✅ 单模型 | ⭐⭐⭐ |
| RM+GB_A (5fold) | **-0.00005** | ✅ 3模型同特征集等权 | ⭐⭐⭐ |
| CB | -0.00025 | ✅ 单模型 | ⭐⭐⭐ |
| CB+numTE | -0.00030 | ✅ 单模型 | ⭐⭐⭐ |
| HGB | -0.00039 | ✅ 单模型 | ⭐⭐⭐ |
| XGB+numTE | -0.00051 | ✅ 单模型（但TE有害） | ⭐⭐ |
| XGB | -0.00088 | ✅ 单模型 | ⭐⭐ |
| HGB+numTE | +0.00009 | ⚠️ 单模型gap翻转 | ⭐⭐ |
| HGBC+numTE | +0.00024 | ⚠️ 单模型OOF高估 | ⭐ |
| 3way numTE | +0.00012 | ❌ 信息不对称(XGB 17d, CB/HGB 38d) | ❌ |
| 4way numTE | +0.00017 | ❌ 信息不对称 | ❌ |
| RM+HGBC+GB_A | +0.00020 | ❌ HGBC OOF高估传染blend | ❌ |

### 核心规律

1. **Gap为负**（OOF < LB）= OOF保守 = 可信赖
   - GBDT单模型（无TE）：gap = -0.00025 ~ -0.00088
   - RM：gap ≈ -0.00003
   - 同特征集等权blend：gap ≈ -0.00005
   
2. **Gap为正**（OOF > LB）= OOF高估 = 不可信赖
   - HGBC+numTE：+0.00024（OOF高估）
   - 含信息不对称的blend：+0.00012 ~ +0.00020

3. **Gap翻正是信息不对称的信号**
   - 正常GBDT单模型gap为负（-0.00025~-0.00088）
   - 含信息不对称的blend gap翻正
   - **gap从负翻正 ≈ 此blend有问题**

## LB预测公式（基于单模型LB校准）

### 方法：单模型LB校准法

不再用OOF直接预测LB，而是：

```
1. 对每个成分模型，用已知单模型LB校准：LB_i = OOF_i + correction_i
2. Blend LB ≈ weighted_blend(corrected_LB_i) + diversity_bonus
```

### 校正值

| 模型 | correction = LB - OOF | 来源 |
|------|----------------------|------|
| RealMLP | +0.00003 | 实测 |
| CB (no TE) | +0.00025 | 实测 |
| CB+numTE | +0.00030 | 实测 |
| HGB (no TE) | +0.00039 | 实测 |
| HGB+numTE | -0.00009 | 实测（gap翻转！） |
| XGB (no TE) | +0.00088 | 实测 |
| HGBC+numTE | -0.00024 | 实测（OOF高估） |

### Blend LB预测

```
blend_OOF = Σ(w_i × OOF_i)
blend_correction = Σ(w_i × correction_i)
predicted_LB ≈ blend_OOF + blend_correction + diversity_bonus
```

其中 diversity_bonus 取决于模型间多样性：
- 同特征集GBDT等权blend：+0.00002（极小）
- RM+GBDT blend：+0.00005~+0.00010
- 含信息不对称的blend：-0.00010~-0.00017（负bonus！）

### 实测验证

| Blend | blend_OOF | blend_correction | +diversity | predicted | actual LB | error |
|-------|-----------|-----------------|------------|-----------|-----------|-------|
| RM0.55+GB_A0.45 | 0.95060 | +0.00030 | +0.00005 | 0.95095 | 0.95065 | -0.00030 |

**问题：此公式过于乐观。** 因为blend后的LB不等于单模型LB的加权平均。多样性bonus的量级难以估计。

### 更实用的预测规则

**直接用gap信号判断OOF是否可信**：

| blend gap估算 | OOF可信度 | 预测LB |
|--------------|----------|--------|
| gap < 0 | ✅ OOF保守，LB ≥ OOF | OOF + 小正值 |
| 0 < gap < +0.00010 | ⚠️ 可能高估 | OOF - 0.00005 |
| gap > +0.00010 | ❌ OOF高估 | OOF - 0.00010~0.00020 |
| gap > +0.00020 | ❌❌ 严重高估 | OOF - 0.00020+ |

gap估算方法：如果blend含信息不对称（成分模型使用不同特征集），gap大概率翻正。

## 最优Blend策略分析

### 问题：为什么numTE单模型LB提升，blend LB反而下降？

| 实验 | CB LB | HGB LB | Blend LB |
|------|-------|--------|----------|
| 无numTE | 0.94947 | 0.94963 | **0.95065** (via GB_A+RM) |
| 有numTE | 0.95021 | 0.94982 | 0.95050 (3way+RM) |

CB LB涨了+0.00074，HGB LB涨了+0.00019，但blend LB反而降了-0.00015。

**原因：信息不对称**
- 3way numTE中，XGB用17d（无TE），CB/HGB用38d（含TE）
- 即使去掉XGB，CB和HGB之间虽然都用numTE，但之前3way的XGB仍存在于OOF中
- 更深层原因：**不同特征集的模型，其OOF预测的错误模式不同，这种差异在训练集上看起来是多样性，但在测试集上不泛化**

### 下一步验证方向

**方案C**：RM + CB_numTE + HGB_numTE（3-way，XGB排除，CB/HGB都用38d）

此方案消除了主要模型间的信息不对称：
- CB和HGB看到相同的38d特征集
- 只有XGB（已排除）用不同特征集
- numTE对CB和HGB的LB提升是真实存在的

预测LB：
- CB_numTE OOF校准后 ≈ 0.94991 + 0.00030 = 0.95021
- HGB_numTE OOF校准后 ≈ 0.94991 - 0.00009 = 0.94982
- RM OOF校准后 ≈ 0.95058 + 0.00003 = 0.95061
- 无信息不对称，diversity_bonus可能为正
- 乐观估计LB ≈ 0.95070+
- 保守估计LB ≈ 0.95065（与当前持平）

## 核心结论

1. **OOF-LB Gap是信息不对称的可靠信号**：gap翻正（>0）意味着OOF高估
2. **numTE对CB和HGB的LB提升是真实的**，但blend时信息不对称会抵消这个优势
3. **单模型LB高 ≠ blend贡献大**：blend价值来自多样性
4. **信息不对称是blend的天敌**：即使各成分模型LB提升，不对称仍导致blend LB下降
5. **最佳策略：让所有GBDT模型看到相同特征集**，利用算法差异而非特征差异产生多样性
6. **XGB绝不能使用TE特征**（LB从0.94896暴跌到0.94680）
7. **所有numTE blend方案全军覆没**：无论怎么组合（3-way/4-way/等权/独立权重），只要GBDT内部存在不同特征集，blend LB就不如同特征集等权blend
8. **当前不可超越的基线**：RM0.55+GB_A(17d eq3)0.45 = LB 0.95065
